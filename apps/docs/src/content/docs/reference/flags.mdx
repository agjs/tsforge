## Feature flags

Read live from [`config/flags.ts`](https://github.com/agjs/tsforge/blob/main/packages/core/src/config/flags.ts).

| Variable | Default | Toggles |
| --- | --- | --- |
| `TSFORGE_HASHLINE` | ON (`≠ "0"`) | hashline read annotations + `edit_lines` tool |
| `TSFORGE_TTSR` | ON (`≠ "0"`) | stream-interrupting TTSR rules |
| `TSFORGE_LSP_WRITE_FEEDBACK` | ON (`≠ "0"`) | type diagnostics on edit/create |
| `TSFORGE_NO_LSP_TOOLS` | off | withhold LSP navigation tools (`=1`) |
| `TSFORGE_LEGACY_FEEDBACK` | off | legacy gate-feedback parser (`=1`) |
| `TSFORGE_NO_ASTGREP` | off | disable ast-grep rewrite in settleGate (`=1`) |
| `TSFORGE_FORCE_TOOLS` | off | force `tool_choice: required` + stop tool (`=1`) |

## Model / inference

| Variable | Default | Toggles |
| --- | --- | --- |
| `TSFORGE_BASE_URL` | `http://localhost:8000/v1` | OpenAI-compatible API endpoint |
| `TSFORGE_MODEL` | `qwen3.6-27b` | model name |
| `TSFORGE_API_KEY` | unset | API key |
| `TSFORGE_MAX_TOKENS` | `16384` | max output tokens |

| `TSFORGE_CONTEXT_WINDOW` | `32768` | context window for gauge + compaction |
| `TSFORGE_COMPACT_AT` | `0.8` | fraction triggering auto-compaction |

## Session / paths

| Variable | Default | Toggles |
| --- | --- | --- |
| `TSFORGE_HOME` | `~` | root for `~/.tsforge/{sessions,logs,models.json}` |
| `TSFORGE_NO_PERSIST` | off | any set value disables disk session persistence |
| `TSFORGE_SESSION_TTL_DAYS` | `30` | days before prune deletes old sessions |

## Timeouts

| Variable | Default | Toggles |
| --- | --- | --- |
| `TSFORGE_RUN_TIMEOUT_MS` | `120000` | `run` tool shell timeout (`0` = none) |
| `TSFORGE_GATE_TIMEOUT_MS` | `600000` | accept gate timeout (`0` = none) |
