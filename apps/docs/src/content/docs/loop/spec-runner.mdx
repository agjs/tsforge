## What it does

`runSpec(spec, cwd, agent, parse?)`:

1. Runs each task through the [implement loop](/loop/implement/) in listed order.
2. The first task that doesn't reach `done` **blocks** the spec (returns `{ status: "blocked", results }`).
3. When every task is green, the spec's own **`verify`** command must also pass — the whole-spec gate. Then `{ status: "done" }`.

## Live eval

`bun run packages/core/scripts/eval-spec.ts` — a `math` spec with two tasks (fix `add`, fix `mul`) + `verify: bun test`. The real model:

- `add` → `done` in 1 cycle (`return a + b`)
- `mul` → `done` in 1 cycle (`return a * b`)
- whole-spec `verify` green → spec `done`

## Deliberately absent (next)
