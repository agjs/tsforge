This site is not marketing. It is **our living understanding of the harness** — written before the code, one slice at a time.

We build greenfield for one reason: to understand the system *inside out*. Building is the vehicle; comprehension is the destination. So every part must justify its own existence — if we can't explain it to a six-year-old, we don't understand it yet, and we don't build it yet.

## How to read this site

- **[North star](/vision/north-star/)** — what we believe we'll achieve. Everything else is derived by working backwards from it.

The site grows one section at a time. Each subsystem gets its own page when its slice begins, written in this order: **doc (the outcome) → test (the acceptance contract) → build (to green)**. Docs explain the *why*; the gate enforces the *what*.
