## What it does

`modelAgent(provider)` returns an `IAgent`. Each cycle it:

1. **Reads the declared files** (`task.files`) into context
2. Sends files + acceptance command + current failures, advertising **`edit`**, **`edit_lines`**, and **`create`** tools
3. Applies each tool call through the [edit engine](/edit/engine/)
4. Runs the [repair ladder](/uplift/repair-ladder/) on rejected tool args before returning feedback

## Tool-call repair

Malformed tool calls don't waste a full model turn:

| Level | Fix |
| --- | --- |
| L0 | unwrap autolinks, drop null fields |
| L1 | coerce JSON strings to arrays, trim fences |
| L3 | targeted re-ask with field name + example |

See [repair ladder](/uplift/repair-ladder/) for details.

## The live eval that shaped it

Run `bun packages/core/scripts/eval-sum.ts` against the local model:

| Setup | Result |
| --- | --- |
| Model given file + test directly | perfect `edit` (exact, unique `oldString`) |
| ModelAgent **blind** (errors only) | `stuck/stalled` |
| ModelAgent **with file context** | `done` in **1 cycle** |
