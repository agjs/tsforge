## How packs activate

1. **Detect** — read `package.json` deps and config files; match against `PACK_REGISTRY`
2. **Configure** — apply `tsforge.config.json` overrides ([config](/guardrails/config/))
3. **Gate** — run enabled pack rules via strict ESLint config on every validation

Both paths use the same packs: greenfield (constitution bring-up) and existing-code (detect-gate).
