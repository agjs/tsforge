## edit — exact string replace

`applyEdit(cwd, { file, oldString, newString })`

| Matches | Result |
| --- | --- |
| 1 | `{ ok: true }`, file written |
| 0 | `{ ok: false, reason: "not-found" }` |
| >1 | `{ ok: false, reason: "ambiguous", matches }` |
| missing file | `{ ok: false, reason: "missing-file" }` |

Best when the model has full file context and can produce a unique snippet.

## edit_lines — hashline line edits

`applyHashlineEdit(cwd, { file, anchor, ops })`

Content-hash-anchored line-range edits with snapshot recovery on stale anchors.

| Reason | Meaning |
| --- | --- |
| `stale-anchor` | hash mismatch — re-read for current `#HASH` |
| `stale-anchor-conflict` | 3-way merge failed — adjust ops |
| `no-anchor` | must read file first |

Full format: [hashline](/uplift/hashline/). Disable with `TSFORGE_HASHLINE=0`.

## create — new file only

`applyCreate(cwd, { file, content })`

Refuses to overwrite (`{ ok: false, reason: "exists" }`). Parent dirs auto-created.

## Write diagnostics

Both edit tools append [instant type diagnostics](/uplift/write-diagnostics/) on success (default ON).
